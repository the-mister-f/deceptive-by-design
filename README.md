# 🕵️‍♂️ Deceptive by Design: UX Dark Patterns Experiment

This repository accompanies the bachelor thesis:  
**"Deceptive by Design: Assessing the Impact of UX Dark Patterns on Engagement and Trust in Digital Products"**  
by **Firas Najar** (submitted April 11, 2025).
It contains the experimental materials, prototypes, and scripts used to evaluate how UX dark patterns influence user behavior and perceived trust.

---

## 📘 Overview

In today's digital product landscape, UX design is often optimized for business outcomes rather than user autonomy. This project investigates the behavioral impact of **dark patterns**—interface design tactics that manipulate users into taking unintended actions.

A **controlled online experiment** was conducted using a nutrition-tracking app prototype. The study involved **107 participants**, randomly assigned to one of three interface versions:

- ✅ **Control** – Transparent, user-friendly UX
- ⚠️ **Mild Manipulation** – Subtle dark patterns (e.g., pre-checked boxes)
- ❌ **Extreme Manipulation** – Aggressive dark patterns (e.g., forced continuity, visual interference)

Key findings include:
- Dark patterns **significantly increased engagement** (e.g., more sign-ups and data sharing)
- **Trust decreased**, especially in emotionally and transactionally sensitive areas
- **Digitally literate users were more resistant** to manipulation
